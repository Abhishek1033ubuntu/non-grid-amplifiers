# 03. Full-Scale 3-Way Hybrid Hermetic Amplifier

## Executive Summary
A complete, non-grid, full-bandwidth ($20\text{ Hz} - 20\text{ kHz}$) acoustic amplifier. By combining a 3-way parallel crossover network with a hermetically sealed Helium pneumatic medium ($\rho = 0.179\text{ kg/m}^3$), this system overcomes high-frequency mass choke and delivers clean net acoustic gain.

## Off-Grid Features
* **Manual Cycle Compressor:** Integrated micro-piston ($2.5\text{ cm}^3$ displacement) for manual foot-pedal top-ups to maintain the $1.5\text{ atm}$ helium baseline.
* **Leak Rate Standard:** Mass spec tested to $< 1 \times 10^{-9}\text{ mbar}\cdot\text{L/s}$ via copper pinch-off cold welds.
